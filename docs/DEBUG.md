# 调试功能说明

本项目包含了一套调试工具，用于帮助诊断生产环境中的问题。

## 🔧 调试工具

### 1. 调试页面 (`/debug`)
- **功能**: 提供系统状态的可视化界面
- **访问控制**: 
  - 开发环境：所有用户可访问
  - 生产环境：仅限指定管理员邮箱
- **功能包括**:
  - 环境变量检查
  - 数据库连接状态
  - 用户认证状态
  - 用户设置流程测试

### 2. 调试 API (`/api/debug/db-status`)
- **功能**: 返回系统状态的 JSON 数据
- **访问控制**: 
  - 开发环境：无限制
  - 生产环境：需要设置 `ENABLE_DEBUG_API=true`

## 🛡️ 安全设置

### 生产环境访问控制

#### 调试页面访问控制
在 `app/[locale]/debug/page.tsx` 中修改允许的管理员邮箱：

```typescript
const allowedEmails = [
  'your-admin@example.com',
  // 添加其他管理员邮箱
];
```

#### 调试 API 访问控制
在 Vercel 环境变量中设置：
```
ENABLE_DEBUG_API=true  # 启用调试 API
ENABLE_DEBUG_API=false # 禁用调试 API（推荐）
```

## 📋 使用指南

### 开发环境
1. 直接访问 `/debug` 页面
2. 所有功能无限制使用

### 生产环境
1. **启用调试功能**:
   - 在 Vercel 项目设置中添加环境变量 `ENABLE_DEBUG_API=true`
   - 重新部署项目

2. **访问调试页面**:
   - 使用管理员账户登录
   - 访问 `/debug` 页面

3. **调试完成后**:
   - 移除或设置 `ENABLE_DEBUG_API=false`
   - 重新部署项目

## 🔍 调试信息说明

### 环境变量检查
- ✅ **已配置**: 环境变量存在且不为空
- ❌ **未配置**: 环境变量缺失或为空

### 数据库连接状态
- **客户端连接**: 使用 `NEXT_PUBLIC_SUPABASE_ANON_KEY` 的连接
- **服务端连接**: 使用 `SUPABASE_SERVICE_ROLE_KEY` 的连接
- **整体状态**: 
  - 🟢 **健康**: 两个连接都成功
  - 🟡 **异常**: 只有一个连接成功
  - 🔴 **失败**: 两个连接都失败

## 🚨 注意事项

1. **生产环境安全**:
   - 调试功能包含敏感信息，请谨慎使用
   - 调试完成后立即禁用相关功能

2. **性能影响**:
   - 调试 API 会执行数据库查询，频繁调用可能影响性能
   - 建议只在需要时使用

3. **日志记录**:
   - 所有调试操作都会记录到控制台
   - 生产环境日志可在 Vercel Functions 页面查看

## 🗑️ 移除调试功能

如果你想完全移除调试功能，可以删除以下文件：
- `app/[locale]/debug/page.tsx`
- `app/api/debug/db-status/route.ts`
- `docs/DEBUG.md`

并从相关代码中移除调试相关的日志输出。

## 📞 故障排除

### 常见问题

1. **"访问被拒绝"**
   - 检查是否使用正确的管理员账户登录
   - 确认邮箱地址在允许列表中

2. **"调试 API 在生产环境中被禁用"**
   - 在 Vercel 环境变量中设置 `ENABLE_DEBUG_API=true`
   - 重新部署项目

3. **数据库连接失败**
   - 检查 Supabase 项目状态
   - 验证环境变量配置
   - 确认数据库表已正确创建

4. **环境变量显示"未配置"**
   - 检查 Vercel 项目的环境变量设置
   - 确认变量名称拼写正确
   - 重新部署项目以应用新的环境变量
